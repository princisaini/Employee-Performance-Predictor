# Data Dictionary

All records are synthetically generated. No real employee or company data is used.

| Field | Type | Meaning | Model input? |
|---|---|---|---|
| employee_id | string | Artificial row identifier | No |
| department | category | Simulated department | Yes |
| role | category | Simulated job role | Yes |
| tenure_years | numeric | Simulated tenure | Yes |
| prior_projects_completed | numeric | Prior-period completed projects | Yes |
| workload_hours_week | numeric | Average weekly workload | Yes |
| attendance_rate | numeric | Simulated attendance proportion | Yes |
| training_hours | numeric | Prior-period training hours | Yes |
| skill_assessment | numeric | Simulated skills assessment | Yes |
| manager_feedback_score | numeric | Simulated feedback score, 1–5 | Yes |
| engagement_score | numeric | Simulated engagement score, 1–5 | Yes |
| overtime_hours | numeric | Weekly overtime | Yes |
| future_performance_score | numeric | Synthetic score used to create target | **No — label source** |
| performance_rating | category | Low / Medium / High target | Target |

The target is generated by a transparent artificial formula with random noise. It is not an observed appraisal outcome. Age, gender, ethnicity, disability, religion, and salary are not generated or used.
